### 표 서식

- 머리행 `002060` + 흰 글자 Bold 중앙
- **본문 줄무늬 없음** (전부 흰 배경)
- 「구분」열은 동작 어미만 파랑
- 「내용」열은 첫 줄에만 불릿 `•` + 내어쓰기, 이후 줄 들여쓰기
- 핵심 조건은 파랑 + 노랑 형광 이중 강조

### 강조 마크업 (spec.json 안)

| 표기 | 결과 |
|---|---|
| `[[텍스트]]` | 파랑 `0000FF` |
| `{{텍스트}}` | 파랑 + 노랑 형광 `FFFF00` |
| `\n` | 셀·문단 내 줄바꿈 |

### 인포그래픽 spec

```json
"infographic": {
  "heading": "4. 조정 내용 종합 정리",
  "before": {"label":"종  전","value":"222만 원/㎡","caption":"'26.3.1 정기 고시","note":"정기 고시 (3.1 / 9.15)"},
  "after":  {"label":"변  경","value":"223만 7천 원/㎡","caption":"'26.7.15 비정기 조정 고시","note":"㎡당 +1만 7천 원 (0.77%↑)"},
  "cards": [
    {"icon":"chart","title":"조정 사유","lines":["고강도 철근 가격","약 18.6% 상승"]}
  ]
}
```

`before`/`after`는 **한 줄 핵심 수치**만, `cards`는 3~5개 권장.
쓸 수 있는 `icon`: calendar · person · house · clock · chart · won · check · gauge · scale · file · arrow · building · percent · bell
(추가하려면 `scripts/make_icons.js`의 `SET`에 react-icons 컴포넌트명을 넣고 재실행)

### 자동 맞춤

한글 1em / 영숫자 0.52em로 실제 텍스트 폭을 계산 →
요약 박스·표 행·의견 바 높이를 내용량에 맞춰 산정, 남는 여백은 균등 분배,
그래도 넘치면 폰트를 0.5pt씩 자동 축소(하한 8.5pt).
인포그래픽이 있으면 흐름표는 행당 0.60" 이내로 묶어 중단 공간을 확보한다.

## [A] 법규 변경 보고사항 (rev.2)

```bash
python3 scripts/build_legal_sheet.py 원본.xlsx spec/legal_2026-07.json 출력.xlsx
```

**두 개 탭을 함께 최신화한다.**
1. 당월 `YYYY.MM 영업계획팀` 탭 신규 생성 (품의용 갑지 바로 뒤)
2. `품의용 갑지` 탭을 당월 내용으로 교체 (6pt 축약 인쇄본)

### 원본 보존 방식

과거 시트(2019~2020년분)에 도형이 들어 있어 **openpyxl 왕복 저장 시 유실**된다.
따라서 ZIP/XML을 직접 편집하고, 서식은 원본 `styles.xml`의 스타일 인덱스를 재사용한다.

실행 후 변경되는 파트는 4개뿐 —
`[Content_Types].xml` · `workbook.xml` · `workbook.xml.rels` · `sheet1.xml`(품의용 갑지).
나머지 시트 XML 75개는 바이트 단위로 그대로 유지된다.

### 조문 행 분류 (`rows[].kind`)

| kind | 변경전(C) | 변경 후(D) |
|---|---|---|
| `head` | 조문 표제 — 남색 볼드 `151594` | 동일 |
| `same` | 변동 없음 — 회색 `444444` | 동일 |
| `change` | 빨강 `FF0000` | 파랑 `0000CD` |

### 서식

| 위치 | 월별 탭 | 품의용 갑지 |
|---|---|---|
| 열 너비 | A 17.2 / B 31.7 / C 94.1 / D 96.4 / E 6.9 | A 2.2 / B 10.3 / C·D 35.7 |
| 제목 | A2:D2 나눔바른고딕 22 Bold, 노랑 `FFFF00` | 없음 (2행이 머리행) |
| 머리행 | 통보부서 / 법률명칭 / 변경전·변경 후 / 당사에 미칠 영향 | 구분 / 현행 / 개선 |
| 조문 본문 | Tahoma 12.1 | 맑은 고딕 6.0 |
| 개정이유 | B 라벨 + C:D 병합, 나눔바른고딕 12 | B 라벨 + C:D 병합, 맑은 고딕 6 |
| 인쇄 | A3 가로, fitToPage, scale 78 | A3 가로, fitToPage, scale 100 |

행 높이는 열 너비 대비 글자수(한글 1자 ≈ 2 x pt/11 문자폭)로 자동 산정한다.

### 당사 관련성 표기

일부개정이라도 당사 사업(아파트·오피스텔·노인복지주택)과 무관하면
`impact` 에 **"당사와 관련없음"** 을 적는다. E열에 빨강으로 들어가고,
해당 법령 블록 전체(조문행 + 개정이유행)에 세로 병합된다.

| 변경 없음 | `2026년 7월 법규 변경사항 없음` |
